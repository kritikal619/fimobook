# J리그 경력 표시와 검색

- 선수 상세의 기존 경력에서 일본 구단을 인식해 `J리그`를 표시한다. 원본의 구단명·기간·임대 여부는 유지한다.
- 세부검색과 스쿼드 검색에서 `전체경력 포함`을 선택하면 `일본 J리그`와 실제 경력 데이터에 있는 구단이 표시된다. J1·J2·J3를 통합해 승강에 영향받지 않는 과거 경력 검색을 제공한다. 현재 소속팀 모드는 기존 카드 기반 기준을 유지한다.
- `jleague_clubs.py`의 정확한 구단명·별칭 목록을 상세 표시, 검색, `scripts/sync_fco_club_careers.py`가 함께 사용한다. 구단명 일부만으로 대학·대표팀·다른 나라 구단을 추정하지 않는다.
- 기존 명령 `python scripts/sync_fco_club_careers.py`로 경력을 갱신하면 알려진 일본 구단의 `league`가 자동 저장된다. 기존 JSON도 실행 시 같은 목록으로 분류하므로 재수집이 필요하지 않다.
- 경력 JSON 또는 `instance/fco_allp.js`가 교체되면 파일 변경을 감지해 상세·검색 캐시를 다시 만든다. 경력 갱신은 선수 카드/이미지 정기 갱신 작업과 별개이며, 이 변경으로 별도 예약 작업을 추가하지 않는다.
- 새로운 J리그 가입 구단이나 원본의 새로운 표기가 생기면 `JLEAGUE_CLUBS`에 한 번 추가한다. 알 수 없는 구단은 임의로 J리그로 분류하지 않는다.

공식 구단 목록: https://www.jleague.jp/en/j1/club/ · https://www.jleague.jp/en/j2/club/ · https://www.jleague.jp/en/j3/club/
