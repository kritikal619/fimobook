# 카페 스쿼드 파워랭킹 집계

## Codex에 요청하는 명령문

아래 문장을 복사하고 URL만 바꾸세요. 별도로 등록해야 하는 슬래시 명령어가 아닙니다.

```text
이 카페글을 파워랭킹으로 집계해줘: [카페 URL]
TOP 1–100의 모든 스쿼드를 읽고, 순위표와 스쿼드 닉네임을 연결해.
선수명, 카드 테두리, 선수 사진을 피모북 player_data.json의 넥슨 원본
bimage/pimage와 카드별로 대조해서 정확한 클래스와 CID를 기록해.
TOP 1–50 / TOP 51–100 / 통합을 나누고 실제 배치 포지션별로
‘클래스 선수 / N명’과 사용 랭커의 순위·닉네임을 정리해.
클래스는 통용 별칭 대신 실제 게임의 공식 클래스명을 표시해.
각 스쿼드 11자리, GK 1자리, 전체 1,100자리와 카드별 사용자 수를 검산해.
순위나 카드가 불분명하면 임의로 확정하지 말고 원본 번호와 확인 상태를 남겨.
reports/ranking-review-[날짜]-top100/에 full-results.md, 1100-player-audit.json,
CSV, 원본 스쿼드 사진, 카드 사진, 한 줄에 카드 하나인 index.html을 만들어.
이전 집계 날짜는 보존하고 파워랭킹 페이지에 새 날짜를 추가해.
```

카페가 로그인으로 막히면 로그인된 브라우저에서 원문과 스쿼드 사진을 읽습니다.
카드 이름이나 클래스는 글의 요약을 그대로 신뢰하지 않고 실제 카드 그림으로 확인합니다.
로컬 static/card, static/faceon 캐시가 원본과 다르면 player_data.json의 넥슨 이미지 주소를 기준으로 대조합니다.

## 검토 완료한 로그에서 결과를 다시 생성하는 CLI

```bash
python3 scripts/import_verified_power_ranking.py \
  --audit reports/ranking-review-2026-09-30-top100/1100-player-audit.json \
  --date 2026-09-30 \
  --source-url 'https://cafe.naver.com/f-e/cafes/25259079/articles/1740964' \
  --report reports/ranking-review-2026-09-30-top100/full-results.md
```

이 명령은 **대조가 끝난 JSON을 집계하고 Markdown과 페이지 데이터를 생성**합니다.
카페 URL에서 자동으로 이미지를 판독하는 OCR 명령은 아닙니다. 원문 판독과 시각 대조는 위 Codex 요청으로 진행합니다.
새 날짜에는 날짜와 입력·출력 경로를 바꿉니다. 이미 존재하는 날짜는 교체하고 다른 날짜는 유지합니다.

각 행의 필수 필드:

| 필드 | 의미 |
|---|---|
| source_index | 원문 스쿼드 순서. 각 11자리의 안정적인 식별자 |
| rank | 순위표에서 확인한 1–100. 닉네임 불일치는 null |
| user | 스쿼드 화면의 닉네임 |
| range | top_1_50 또는 top_51_100 |
| position | 실제 배치 ST/CF/LW/RW/CAM/CM/CDM/LM/RM/LB/CB/RB/GK |
| cid, player_name | 대조한 피모북 카드 CID와 정확한 선수명 |
| season, class_label, class_name | 대조한 클래스 코드, 표시명, 정식 클래스명 |

다른 성장 단계의 이터널은 동일한 season과 pid로 묶습니다. 포지션이 다르면 각각 집계합니다.
표시명은 `static/data/power-ranking-class-names.json`의 공식 클래스명을 사용합니다.
UTOTS·UTOTY·FINAL·MOMENT는 공식 클래스명 뒤에 세부 카드 유형으로 구분하며, 집계 키는 유지합니다.
새 클래스의 공식 명칭은 넥슨 스쿼드 메이커와 공식 코치노트에서 확인한 뒤 이 매핑에 추가합니다.
그림이 같은 기본 OVR 변형은 대표 CID를 남기며, 화면의 강화된 OVR을 기본 OVR로 주장하지 않습니다.
새 집계의 카드 합성 PNG는 `static/ranking/[날짜]/[cid].png`에 넣습니다.
원본 합성 PNG는 넥슨 background와 face를 같은 256×256 캔버스에 겹칩니다. 페이지에서는 상세 페이지와 동일한 FimoCardArt 렌더러와 card_art_metadata를 사용해 기본 OVR, 카드의 원래 포지션, 선수명, 국적·리그·클럽 로고를 같은 위치와 색상으로 표시합니다. 집계 배치 포지션과 카드의 원래 포지션은 구분합니다.

## 페이지 디자인 기준

2026-10-05 Claude 웹 채팅의 기록표 제안을 검토해 적용했습니다.
장식 문구·요약 박스 대신 작은 제목과 집계 정보, 구분선으로 카드 행을 정렬합니다.
공식 클래스명은 줄바꿈을 허용하고 사용 랭커 명단은 펼쳐봅니다.
사용률은 선택한 범위의 스쿼드 수가 분모이며, 비율과 사용 인원/분모를 함께 표시합니다.
과거 요약 데이터처럼 스쿼드 수가 확인되지 않으면 사용률을 표시하지 않습니다.

사용 랭커 이름은 원본 스쿼드 모달과 연결합니다. 날짜별 원본 사진 100장을 `static/ranking/[날짜]/squads/[source_index 두 자리].png`에 복사합니다. 순위와 source_index가 다를 수 있으므로 이미지 연결에는 source_index를 사용합니다.
